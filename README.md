# lucia6-site

Static link page for Lucia (AI persona): videos, photos, links to X and Instagram.
Plain HTML, no build step. Deploy on Vercel as a static site (framework preset: Other).

- `index.html`: the whole page (styles and scripts inline)
- `img/`: photos, videos and video posters
- `og.jpg`, `favicon.png`, `apple-touch-icon.png`: link preview and icons

Once the site has its final address, change the two `/og.jpg` links in `index.html`
to the full URL (e.g. `https://lucia6.ai/og.jpg`) so link previews work everywhere.
